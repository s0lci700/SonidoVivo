# Versión 00 · Sitio HTML tradicional

Este proyecto es el **punto de partida** del ejemplo integrador de Semana 08.

## Páginas

- `index.html`
- `productos.html`
- `contacto.html`
- `login.html`
- `admin.html`

## Conceptos

- HTML semántico: `header`, `nav`, `main`, `footer`.
- CSS común para las cinco páginas.
- JavaScript para productos, validaciones y login.
- `localStorage` para simular sesión.

## Ejecutar

Usar **Live Server** desde VS Code.
