Bienvenido

Este sitio tiene cinco páginas HTML tradicionales. La meta será migrarlo paso a paso a React.

¿Qué vamos a transformar?

  • Header, navegación y footer repetidos → componentes reutilizables.
  • Cinco archivos HTML → páginas React.
  • Links entre archivos → React Router.
  • Login tradicional → estado, localStorage y ruta protegida.
  • Validaciones → funciones reutilizables y pruebas con Vitest.
