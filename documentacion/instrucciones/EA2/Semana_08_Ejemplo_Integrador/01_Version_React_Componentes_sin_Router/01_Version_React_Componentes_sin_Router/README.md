# Versión 01 · React + componentes, sin Router

## Proviene de

`00_Sitio_HTML_Estatico_5_Paginas`.

## Objetivo

Comprender **componentes, props y reutilización** antes de introducir React Router.

## Ejecutar

```bash
npm install
npm run dev
```

## Observar

- `Header.jsx`, `Navbar.jsx` y `Footer.jsx` aparecen una sola vez.
- `App.jsx` mantiene `paginaActual` con `useState`.
- `Productos.jsx` usa `ProductoCard` y props.
- Las imágenes de catálogo permanecen en `public/images/productos/`.
