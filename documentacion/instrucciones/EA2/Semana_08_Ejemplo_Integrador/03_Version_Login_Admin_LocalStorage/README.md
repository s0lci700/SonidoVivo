# Versión 03 · Login + Admin + localStorage

## Proviene de

Versión 02.

## Objetivo

Agregar comportamiento real a los formularios y simular un flujo de autenticación.

## Login

- Usuario: `admin`
- Contraseña: `admin123`

## Flujo

`Login → validación → localStorage → /admin → cerrar sesión → /login`

## Importante

La autenticación es **solo didáctica**. En P3 debe reemplazarse por Backend/JWT.

## Ejecutar

```bash
npm install
npm run dev
```
