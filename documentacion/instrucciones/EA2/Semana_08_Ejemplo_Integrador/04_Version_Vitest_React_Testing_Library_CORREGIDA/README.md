# Versión 04 · Testing

## Proviene de

Versión 03.

## Objetivo

Aplicar las pruebas de Semana 08 a una aplicación que ya tiene componentes, rutas, formularios y login.

## Ejecutar

```bash
npm install
npm run dev
```

## Pruebas

```bash
npm test
npm run test:watch
npm run test:coverage
```

## Cobertura de ejemplo

Las pruebas se concentran en comportamiento útil:

- validaciones;
- renderizado de ProductoCard;
- validación del Login;
- login correcto y navegación a `/admin`.

No se busca 100% de cobertura por obligación.
